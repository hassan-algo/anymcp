# AnyMCP registry

Community site profiles, categories and curated lists.

- `categories.json`: the categories profiles can use.
- `sites/<domain>/profile.json`: one profile per site. The folder name must equal the profile `id`.
- `lists/<id>.json`: curated bundles of profiles.
- `index.json`: everything above in one file, generated by `npm run build:registry`. Commit it; don't edit it.

Profiles are JSON only, never code. Format: [docs/profile-format.md](../docs/profile-format.md).
How to add one: [CONTRIBUTING.md](../CONTRIBUTING.md).
